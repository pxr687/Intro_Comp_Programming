Data Types, Comparison Operators and Functions#

Note

This page is partly adapted from by Brett and co-authors (2023). See the license page for more information.

Let’s quickly summarise what we have learned so far.

We have looked at variables, where we store named data in our computer’s memory:

# This is a variable assignment statement. 
#`number_3` is the name of the variable, `3` is its value.
number_3 = 3

# The cell above this one created this variable `number_3`. This cell shows the value of the variable.
number_3

3

We also looked at literals, which are values in Python code which are NOT stored as variables:

# This is a literal.
1999

1999

We have also talked about expressions - any piece of Python code that returns a value:

# This is an expression.
2 + 2

4

# This is also an expression, because it returns a value (it is the variable we made earlier)
number_3

3

# This literal is also an expression, beause it returns a value.
1990

1990

We have also use functions, like print():

# The `print()` function.
print('This is the print functon!')

This is the print functon!

You can think of a function like a recipe. We give it some ingredients, and it returns a “meal”.

For the print() function, we give it some input and it displays the input. We used it for text, but we can also use it for numbers:

# The `print()` function (again).
print(10)

10

[Importance of type]

# A number, multiplied by 10.
10 * 10

100

# Text, multiplied by 10.
"This is text!" * 10

'This is text!This is text!This is text!This is text!This is text!This is text!This is text!This is text!This is text!This is text!'

my_string = str(my_float)
