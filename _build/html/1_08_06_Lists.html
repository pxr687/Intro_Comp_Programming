Lists#

Note

This page is adapted from Brett, Rush, Adhikari, Denero and Wagner (2023). See the license page for more information.

Thus far we have seen the following data types:

  • integer (counting number) - int.

  • floating point number (number with decimal point) - float.

  • string (text) - str.

  • boolean (True or False value) - bool.

In data analysis, we often want to put together several numbers, or strings, into a group. This allows us to collect values together into one place, and refer to all the values with a single name. Now that we can refer to all the values with a single name, we can write code that works on the whole group at once.

For example, remember our problem of the three girls in a family of four?

You have seen that we can make four random values, that can be "BOY" or "GIRL", like this:

# Load the Numpy package, and rename to "np"
import numpy as np

# Get four simulated children (50% chance of "BOY", 50% chance of "GIRL")
a = np.random.choice(['GIRL', 'BOY'])
b = np.random.choice(['GIRL', 'BOY'])
c = np.random.choice(['GIRL', 'BOY'])
d = np.random.choice(['GIRL', 'BOY'])

Here, each child number gets their own variable.

a

np.str_('BOY')

b

np.str_('BOY')

c

np.str_('GIRL')

d

np.str_('GIRL')

This gave us one simulated family.

Now imagine that we were trying to simulate a family of 12 children. We would have to give each child their own variable a through l (small L), and then type 12 lines of code to see the value of the variables.

That would be annoying, and impractical when we have to simulate larger numbers, such as the 100 families.

Groups are part of the solution to this problem. Groups (also called sequences or collections can store lots of other values/variables. There are two main types of collection, in Python:

  • Lists - list

  • Arrays - np.array

We will see arrays soon. This page is about lists.

Making a list#

You make a list using square brackets - [ and ].

Here we make a list that contains three integers:

my_numbers = [1, 2, 3]
my_numbers

[1, 2, 3]

More formally, you define a list like this:

  1. the open square bracket character [, followed by

  2. a sequence of zero of more values, separated by commas, followed by

  3. the close square bracket character ].

[1, 2, 3] is a list expression because it is a recipe that results in a value that is a list). We confirm it is an expression by showing that the notebook displays a value:

[1, 2, 3]

[1, 2, 3]

What type of value is it?

type(my_numbers)

list

Here is a list with one value:

another_list = [99]
another_list

[99]

Lists can be empty. To make an empty list, put nothing inside the square brackets, like this:

my_empty_list = []
my_empty_list

[]

A list can have any kind of value as its elements. For example, here is a list of strings:

some_strings = ["Chris", "Andre", "Jessica", "Luke"]
some_strings

['Chris', 'Andre', 'Jessica', 'Luke']

Functions and lists#

Python has some built-in functions that operate on sequences, like lists.

A built-in function is a function that we can use in any Python session, without importing it from a library.

One of these built-in functions is len. Here is a call expression, using the function len on our list:

len(my_numbers)

3

As you might predict, calling len with the list as an argument, returns the number of elements in the list.

Another function that operates on lists is sum. This adds all the elements in the list together, and returns the result:

sum(my_numbers)

6

A half-solution for three girls#

Now we have another way of solving the problem of making the family of four children above. Use Control-Enter a few times on the cell below to see a new family simulated every time:

# Get four simulated children and put them in a list.
# The opening square brackets tell Python the statement is not finished
# when it reaches the end of the first line.
family =  [np.random.choice(['GIRL', 'BOY']),
           np.random.choice(['GIRL', 'BOY']),
           np.random.choice(['GIRL', 'BOY']),
           np.random.choice(['GIRL', 'BOY'])]
# Show the family.
family

[np.str_('BOY'), np.str_('GIRL'), np.str_('GIRL'), np.str_('BOY')]

Note: np.str_ just tells us these are Numpy’s version of str data…

We can use the list method .count() to count the number of girls in this family. Remember a method is a function attached to an object, like a list:

# Count the number of girls.
family.count("GIRL")

2

The cell below simulates a new family, and the last line counts the number of girls in this family:

# Get four simulated children and put them in a list.
# The opening square brackets tell Python the statement is not finished
# when it reaches the end of the first line.
family =  [np.random.choice(['GIRL', 'BOY']),
           np.random.choice(['GIRL', 'BOY']),
           np.random.choice(['GIRL', 'BOY']),
           np.random.choice(['GIRL', 'BOY'])]
# Show the family.
print(family)
family.count('GIRL')

[np.str_('BOY'), np.str_('GIRL'), np.str_('BOY'), np.str_('GIRL')]

2

We could run this code lots of times and write down the number of girls in each family. That would answer our question “what is the probability of a family of 4 having 3 girls?”.

That would take a long time. On the next textbook pages, we will learn some more Python tools to make this process faster and more efficient…
