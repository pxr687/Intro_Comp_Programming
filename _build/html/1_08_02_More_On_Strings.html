More on Strings#

Note

This page is adpted from Brett, Rush, Adhikari, Denero and Wagner (2023). See the license page for more information. One part of the exercise at the end of the page is inspired by the “Strings” lab from the Berkeley data science course, with thanks.

We have used text/string data on earlier pages. On this page, we will go into a little more depth about how to deal with string data in your programs.

Much of the world’s data is text. As we know a piece of text represented in a computer is called a string. A string can represent a word, a sentence, or even the contents of every book in a library. Since text can include numbers (like this: 5) or truth values (True), a string can also describe those things.

The meaning of an expression depends both upon its structure and the types of values that are being combined. So, for instance, adding two strings together produces another string. This expression is still an addition expression, but it is combining a different type of value.

"computer" + "programming"

'computerprogramming'

When you use + with two strings, then Python adds the two strings together without thinking about what the text says. It doesn’t add a space because these are different words; adding space and making sure the text is nice to read is up to the programmer (you).

We can add a space like this:

"computer" + " " + "programming"

'computer programming'

Single and double quotes can both be used to create strings: 'hi' and "hi" are identical expressions. Double quotes are often better because they let you include apostrophes inside of strings.

Like the int() and float() function will change data to int or float, we know that the str() function will change data into the str data type. Using this function, strings can be put together from more than one value.

# Combining different data types into a string.
"That's " + str(1 + 1) + ' ' + str(True) + " pal!"

"That's 2 True pal!"

# Using the `str()` function again to turn numbers into strings.
"There are " + str(50) + " districts in Bangkok."

'There are 50 districts in Bangkok.'

This can be very useful when you are debugging/fixing code, because you can print() out that value of a variables from different parts of the code, which can let you find where errors are happening.

We can also put number variables into the string, using the str() function:

number_of_students = 22

"There are " + str(number_of_students) + " students in the class."

'There are 22 students in the class.'

Multi-line strings#

We can use 3 quotation marks (' or ") instead of one, so that we can make long strings, without needing loads of print() functions!:

print("This is a string on one line.")

This is a string on one line.

# Look at the three quotation marks (""") at the start and end of the string.
print("""       
This string...

...can go over...

...as many lines...

...as I want...
""")

F-strings#

Do not worry about learning how to use f-strings right now (unless you want to). This section is just to tell you about them, so you recognise them in other people’s code. They are very useful, so if you do have some time, I encourage you to play around with them.

We have seen how to put numbers and text together using lots of + symbols and the str function.

A better way to do this is to use f-strings. These take some time to get used to, but you will find them very helpful for showing results and debugging your code.

To use a f-string, just put at “f” at the start of your string!:

f"This is an f-string!"

'This is an f-string!'

Now, inside our f-string, if we put variables, literals or expressions inside curly brackets {}, they will become part of the string:

# Look -------------------------------------------------------------------------------------> HERE!
f"This is an f-string! It can show the value of my `number_of_students` variable like this: {number_of_students}."

'This is an f-string! It can show the value of my `number_of_students` variable like this: 22.'

f"We can also put literals/expressions inside our string, like this: {8 * 100}" 

'We can also put literals/expressions inside our string, like this: 800'

Note that using “f” before the string is allowed in Python, because the Python compiler knows it means “this is an f-string! Let me put variables in it!”. However, we will get errors if we use other letters, as the Python compiler does not know what these mean:

e"This is not allowed!"

  Cell In[15], line 1
    e"This is not allowed!"
     ^
SyntaxError: invalid syntax
