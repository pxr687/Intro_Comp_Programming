An online shopping website gives customers free shipping when their order total is more than 500 baht. A developer writes the following Python code, but it contains a SyntaxError.

Your job is to fix the SyntaxError so the program runs correctly. When it runs correctly, it should ask:

  • is order_total over 500 baht? Then:

    • if yes, show the message "Free shipping!" and make shipping_fee equal 0 baht

    • if no, show the message "Shipping fee applies." and make shipping_fee equal 40 baht

The variable order_total should equal 650 baht.

order_total = 650

if order_total > 500
    print("Free shipping!")
    shipping_fee = 0
    
else
    print("Shipping fee applies.")
    shipping_fee = 40
