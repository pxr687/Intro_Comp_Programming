Conditional Statements - if this happens → then that happens#

Note

This page is adapted from Brett, Rush, Adhikari, Denero and Wagner (2023). See the license page for more information.

In lots of situations, for something to happen, something else has to be true. Another way of saying this is that a condition has to be met.For example:

  • If an app user has an account, then they can login to the app.

  • People in randomized controlled trials get a drug treatment if they have been randomly put in the treatment group.

  • A gambler makes money if she wins her bet.

The structure of all these situations is:

IF this happens → THEN that happens.

On this page we will learn how to talk about these situations using code. A conditional statement is a multi-line statement that lets Python choose among different options based on the truth value of an expression.

Conditional statements can appear anywhere, but they often appear inside functions - they can make a function do something different to different variable types (more on this later)!

A conditional statement always begins with an if header, which is a single line followed by an indented body. To show this, let’s use NumPy to simulate a coin flip. Run the cell a few times to see a few different coin flips. The code which does the coin flip is np.random.choice(['HEADS', 'TAILS']). Each time we run this, it has a 50% chance of giving us the string 'HEADS' and a 50% chance of giving us the string 'TAILS' - just like flipping a real coin!:

# Import the NumPy library.
import numpy as np

# Simulate a coin flip.
coinflip = np.random.choice(['HEADS', 'TAILS'])

coinflip

np.str_('TAILS')

Imagine you and friend are making bets about our coin flip.

You bet ฿20 it will land on 'HEADS' and your friend bets ฿20 it will land on 'TAILS'.

We can get a True or False value to see who one, using comparison operators:

# Did you win?
coinflip == 'HEADS'

False

# Did you friend win?
coinflip == 'TAILS'

True

Re-run the three cells above a few times to see a few new bets, and whether you or your friend won them.

We can represent the full structure of these bets in code using conditional statements and comparison operators together, so that we do not need to use more than one cell.

To show this, remember I said that a conditional statement always begins with an if header, which is a single line followed by an indented body? These are shown in the cell below, read the comments carefully.

# The line below this comment is the conditional header:
if coinflip == 'HEADS': # <------ You MUST end the statement with a colon symbol (:)
    
    # This next line of code is the indented body. 
    # You press the ⭾ key at the start of the line, to make the indent.
    print('You win ฿20!')

Let’s show the conditional statement again, without the comments, so it is cleaner (the code is exactly the same):

if coinflip == 'HEADS': 
    
    print('You win ฿20!')

We can read this conditional statement in English as:

If the coinflip variable has the value 'HEADS', then print the string 'You win ฿20!'.

Go back and run the cell where the coinflip variable is made. Then run the cell with the conditional statement.

If you do this a few times, you will see that there are two things that can happen:

  • You see the message 'You win ฿20!'.

  • Nothing happens.

You see the message if the code in the first cell coinflip = np.random.choice(['HEADS', 'TAILS']) randomly gave us the string 'HEADS'. You see nothing if it gave us 'TAILS'.

The reason for this is that the code in the indented body is only run if the expression directly following if (called the if expression) evaluates True. If the if expression evaluates to a False, then the body of the if will not run.

Your friend might complain that this is not fair, because it only says when you win. So let’s make two conditional statements, one for you winning, and one for your friend winning. The first cell makes a new coinflip variable.

# Simulate a new coin flip.
coinflip = np.random.choice(['HEADS', 'TAILS'])

coinflip

np.str_('TAILS')

# Conditional statement 1.
if coinflip == 'HEADS':
    
    print('You win ฿20!')

# Conditional statement 2.
if coinflip == 'TAILS':
    
    print('Your friend wins ฿20!')

Your friend wins ฿20!

Run these three cells in order a few times. You’ll notice that only one of the conditional statements will show an output each time. This is because:

The the if expression is False, Python does NOT run the code in the indented body of that statement.

The code in the body is only run if the if expression is True.

If you want to cheat your friend, you could write the code as:

if True:
    print('You win ฿20!')

You win ฿20!

In this code you will always win ฿20 because we are hard-coding the if expression to be True. Perfect, but your friend may not be happy…

In contrast, this code will never let you win ฿20:

if False:
    print('You win ฿20!')

You can run that infinite times, and you will never win :( because we are hard-coding the if expression to be False. To see this another way, let’s use some random integer values, instead of strings. We will now write the code so that you see an output every time, even if the if expression is not True.

Conditional Statements with Random Numbers#

The NumPy function np.random.randint() can make random integers for us. This type of random number making is used inside video games, apps, simulation in scientific studies, and many other things.

We can tell np.random.randint() the lowest integer and the highest integer we want - note that for the high value, if we want our highest value to be \(x\) we have to make high equal \(x + 1\):

# Get a random integer between -10 and 10.
np.random.randint(low = -10, high = 11)

7

Let look conditional that makes a variable called result. This variable will be the string 'Positive' if our random integer is positive:

x = np.random.randint(low = -10, high = 11)
result = 'Not sure yet'
if x > 0:
    result = 'Positive'
print(x)
print(result)

Let us work through what Python will do when we evaluate the code above (repeated in the cell below):

  1. x gets the value from np.random.randint(low = -10, high = 11). This is a random int between -10 and +10.

  2. Python evaluates the assignment statement result = 'Not sure yet'. The result variable has the value of "Not sure yet".

  3. Python evaluates the if expression x > 0. The result is the CR of True. This is a true value, so Python will run the body of the if statement.

  4. The body of the if statement is the single line result = 'Positive'. Python reassigns the result variable to have the value: CR of "Positive".

  5. result first evaluates result to get the CR of "Positive", and, as this is an expression, Jupyter shows us the result.

Here’s the code as a code cell - run it a few times to see what happens:

x = np.random.randint(low = -10, high = 11)

result = 'Not sure yet'

if x > 0:
    result = 'Positive'

print(x)
print(result)

-5
Not sure yet

The cell shows 'Positive' if x is a positive number, like 3. But if x is not a positive number, such as -3, then this happens:

  1. x has the value of -3.

  2. result gets the value: "Not sure yet". So far this is the same as for the case of x equal to 3 above.

  3. x > 0 evaluates to False, so Python DOES NOT RUN the body of the if statement.

  4. result evaluates result to get the value "Not sure yet" (because this hasn’t changed), and Jupyter shows us the result.

else statements#

Let us improve our code to give Not positive if x is a negative number. We can do this by adding an else clause.

If the if expression evaluates to a True value, then Python runs the first clause, after the if expression, as before.

If it evaluates to a False value, Python runs the clause following the else, instead.

x = np.random.randint(low = -10, high = 11)

result = 'Not sure yet'

if x > 0:
    result = 'Positive'
    
else:
    result = 'Not positive'
    
print(x)
print(result)

7
Positive

Python sets x to have the value from np.random.randint(low = -10, high = 11).

It checks x > 0 if finds a False value, then it skips the first clause, and runs the clause after else:. This shows 'Not positive'.

If you set x has a positive value, then result will get the value Positive, because Python will evaluate the result = 'Positive' body, and not the result = 'Not positive body.

Notice that the if statement now deals with all possible values of x. Whatever the value of x we with either execute result = 'Positive' or we will execute result = 'Not positive'.

We can now get rid of the first line in the function result = 'Not sure yet' because we will always change result from that value, in the if statement:

# Classify without the unnecessary first assignment.
x = np.random.randint(low = -10, high = 11)

if x > 0:
    result = 'Positive'
    
else:
    result = 'Not positive'

print(x)
print(result)

-1
Not positive

elif statements#

Now imagine we prefer our cell to show 'Negative for negative values and Zero if the input value is 0. It seems like we need three clauses, one each for positive, negative and 0 values.

We can do this by adding an elif clause, where elif is Python’s shorthand for the phrase “else if”.

x = np.random.randint(low = -10, high = 11)

if x > 0:
    result = 'Positive'
    
elif x == 0:  # elif short for "else if"
    result = 'Zero'
    
else:
    result = 'Negative'
    
print(x)
print(result)

7
Positive

Now the cell returns the correct answer when the input is -3, 0, or 3:

x = 3
if x > 0:
    result = 'Positive'
elif x == 0:  # elif short for "else if"
    result = 'Zero'
else:
    result = 'Negative'
print(x)
print(result)

3
Positive

x = 0
if x > 0:
    result = 'Positive'
elif x == 0:  # elif short for "else if"
    result = 'Zero'
else:
    result = 'Negative'
print(x)
print(result)

0
Zero

This helpful diagram (from here) shows what is happening - the colour red means a condition is False, green means it is True:

If x is equal to 3, Python evaluates the if expression x < 0. The expression gives a True value, so Python runs the first clause, sets result to equal “Positive” and skips to the end of the if statement. Finally it evaluates result to show “Positive”.

If x equals 0, evaluates the if expression x < 0. The expression is a False value, so Python moves on to the next clause, which is elif x == 0:. This has another if expression x == 0. It is a True value, so Python runs this clause, and sets result equal to “Zero”. Then it skips to the end of the if statement, and shows result.

If x equals -3, evaluates the if expression x < 0. The expression is a false value, so Python moves on to the next clause, which is elif x == 0. This expression is also a False value so Python moves to the next clause, which is the else: clause, and runs that, setting result to be “Negative”. Now we are at the end of the if statement, and we evaluate and show result.

We can have as many elif statements as we want#

We can have as many elif clauses as we want. For example, imagine we want to classify the number into one of the following categories:

  1. above 10 ('Large positive')

  2. from (not including) 0 through 10 ('Small positive')

  3. exactly 0 ('Zero')

  4. from (not including) 0 through -10 ('Small negative')

  5. below -10 ('Large negative')

Notice that I have changed the low and high values for np.random.randinit(), so that it will now get integers between -100 and 100:

x = np.random.randint(low = -100, high = 101)
if x > 10:
    result = 'Large positive'
elif x > 0:
    result = 'Small positive'
elif x == 0:
    result = 'Zero'
elif x >= -10:  # Greater than or equal to
    result = 'Small negative'
else:
    result = 'Large negative'
    
print(result)
print(x)

Large positive
70

The General Structure of Conditional Statements#

A conditional statement can also have multiple clauses with multiple bodies, and only one of those bodies can ever be executed. The general format of a multi-clause conditional statement appears below:

if <if expression>:
    <if body>
elif <elif expression 0>:
    <elif body 0>
elif <elif expression 1>:
    <elif body 1>
...
else:
    <else body>

There is always exactly one if clause, but there can be any number of elif clauses.

Python will evaluate the if and elif expressions in the headers in order until one is found that is a true value, then execute the corresponding body. The else clause is optional.

When an else header is provided, its else body is executed only if none of the header expressions of the previous clauses are true. The else clause must always come at the end (or not at all).
