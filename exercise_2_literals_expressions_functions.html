Exercise - What are Literals, Expressions and Functions?#

If you need help, open the textbook page for this exercise.

Instructions#

IMPORTANT: If you see a comment which says # DO NOT CHANGE THIS CODE then DO NOT CHANGE THAT CODE. You will probably break the exercise if you do…

ALSO IMPORTANT: in ALL exercises, and ALL assignments/tests/exams. You MUST use the right variable names in your answers.

If the question says “make a variable called answer_1” you MUST call you variable answer_1 or you will NOT get a mark.

If the question says “make a variable called me_and_my_cat” you MUST call you variable me_and_my_cat or you will NOT get a mark.

Exercise#

When you run the cell below it will show 10 questions, one after the other.

You will be shown a Python element and asked if it is a number literal, a text literal, an expression made from two literals or a function.

A box will appear. You should type number literal, text literal, expression made from two literals or function as your answer.

A message will tell you if you are correct or not.

Run the cell below to get started:

# DO NOT CHANGE THE CODE IN THIS CELL. JUST RUN IT.
